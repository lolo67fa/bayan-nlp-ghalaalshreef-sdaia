How does Bayan understand a service request?

Type a request in Arabic or English, or pick an example. Bayan predicts its topic and looks for the closest past case, even when that case is written in the other language.

Try an example

What runs behind this page

  1. Mask

    Emails and Saudi mobile numbers are replaced before any model sees the text.

  2. Topic

    TF-IDF on character 3–5-grams + LinearSVC, the Notebook 03 baseline, retrained at startup on 24 synthetic rows.

  3. Embed

    Multilingual MiniLM puts Arabic and English text in one vector space: 24 past cases, 12 in each language.

  4. Retrieve

    Exact inner-product search (the FAISS IndexFlatIP ranking of Notebook 06) and a no-answer threshold tuned on validation only.
